# Notescapes 🌿

[🌐 View the Live Knowledge Base](https://harshp2008.github.io/Notes/)

## Why Notescapes?

I originally started this project to digitalize my hand-written notes, thinking that having them online would make them faster to write and accessible from anywhere. A simple reason. 

But as I continued to write, finding the time became harder, and I didn’t always know if my notes were the absolute "best-quality". So, I chose to make this repository public to allow others to share doubts, ask questions, and actively contribute.

I'm hoping that with a bit of academic integrity, our collective knowledge will help create high-quality notes that are informative, easy to understand, and concise—while leaving enough room to dive into the nitty-gritty complexity of the IB syllabus.

**🎓 Notescapes is my long-term IB CAS project, and contributing to it can be yours too!**
